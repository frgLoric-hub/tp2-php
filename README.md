# TP2 - PHP

TP réalisé en BTS CIEL2, cours Développement WEB/PHP.

## Exercice 1 : ACHAT
Formulaire permettant de choisir un professeur et un cours parmi des listes,
puis d'indiquer un nombre de séances à commander. Un récapitulatif de la
commande s'affiche, avec un message d'erreur si le nombre n'est pas renseigné.

Fichiers : `index.php`, `exo1_index.php`, `exo1_page2.php`, `exo1_cours.php`

## Exercice 2 : DONS
Formulaire de don caritatif (Nom, Age, Mail, Don). Chaque don est enregistré
dans `resultats.txt`. Une page de résultats affiche la liste des dons, la
somme totale, la moyenne d'âge des donateurs, et un graphique (montant des
dons par personne) généré avec la bibliothèque JPGraph.

Fichiers : `exo2_formulaire.php`, `exo2_traitement.php`, `exo2_resultats.php`,
`exo2_graphique.php`

## Utilisation
Placer le dossier dans `www` (WAMP/XAMPP), démarrer le serveur, puis ouvrir
`index.php` dans le navigateur.
